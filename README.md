# 🎮 MoneyPixel

A gamified personal finance tracking web application built with **Next.js**, **TypeScript**, **Tailwind CSS**, **Prisma**, and **MySQL**, integrated with **Google Gemini AI** for automated receipt scanning.

🔗 **Live Demo:** [https://moneypixel.vercel.app/](https://moneypixel.vercel.app/)

---

## ✨ Key Features

- **Income & Expense Tracking:** Record and categorize daily transactions with real-time financial summaries.
- **AI Receipt Scanning:** Automatically extract expense data from receipt images using **Google Gemini AI**.
- **Gamification System:** Earn EXP, level up, complete quests, and decorate a virtual room to make saving fun.
- **Bilingual Support (TH / EN):** Built-in Thai and English language switching.
- **Authentication:** Secure user sign-in and session management powered by **Auth.js**.

---

## 🛠 Tech Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend & Database:** Node.js, Prisma ORM, MySQL
- **AI & Auth:** Google Gemini API, Auth.js
- **Deployment:** Vercel
